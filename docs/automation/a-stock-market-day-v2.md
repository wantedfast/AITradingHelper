# AI 当日行情 19:00 自动复盘 v2

> 自动化：`AI当日行情 19:00 自动复盘`（ID `ai-19-00`）
>
> 调度：交易日 19:00，`Asia/Shanghai`

## 产品目标

收盘后帮助普通用户看懂今天实际发生了什么，纠正盘中形成的错误感觉，并形成下一交易日可以验证、也可以主动放弃的观察计划。它不是明日涨跌预测，也不推荐股票。

## 双层输出

- 第一层 `beginner_decision`：30 秒回答今天发生了什么、市场是真强还是表面强、明天是否有一个观察方向、满足什么才能继续、出现什么立即放弃、三个时间点分别做什么。
- 第二层：完整保留指数、成交额、涨跌停、市场宽度、连板结构、主线与轮动、上一交易日对比、市场热度样本、来源、数据口径和审计字段。

## v2 契约

最外层必须使用 `schema_version: 2`，`run_id` 固定为 `market-day-YYYY-MM-DD`，并在 `report` 中增加：

```json
{
  "beginner_decision": {
    "stance": "observe | cautious | stand_aside",
    "headline": "今天市场实际走成什么",
    "what_changed": ["相比上一交易日最重要的变化，1 至 3 条"],
    "primary_focus": {"name": "明天最多观察一个方向", "reason": "白话事实依据"},
    "continue_conditions": [
      {"time": "09:35", "observation": "全部满足才继续的现象", "action": "满足后继续观察什么"}
    ],
    "stop_conditions": [
      {"time": "09:35", "observation": "任意出现便放弃的现象", "action": "停止关注，不临时追其他方向"}
    ],
    "timeline": [
      {"time": "09:25", "observation": "看什么", "action": "怎么做", "if_unmet": "不满足怎么办"},
      {"time": "09:35", "observation": "看什么", "action": "怎么做", "if_unmet": "不满足怎么办"},
      {"time": "10:30", "observation": "看什么", "action": "怎么做", "if_unmet": "不满足怎么办"}
    ],
    "backup_focus": {"name": "最多一个备选方向", "condition": "必须独立验证，不能自动切换"},
    "avoid_actions": ["明天最需避免的行为，1 至 3 条"],
    "term_explanations": [{"term": "专业词", "plain": "一句白话解释"}]
  }
}
```

`primary_focus` 和 `backup_focus` 均允许为 `null`。无明确持续方向时必须使用 `stand_aside`，标题明确“明天暂不预设主线”，且 `continue_conditions` 允许为空；任何状态都必须至少有一条停止条件。

## 小白层质量门槛

- 禁止未经解释地出现：强修复、扩散、回流、承接、弱转强、宽度、拥挤度、晋级率、高位负反馈。
- 禁止具体股票名称、代码、排名、十分制评分、上涨概率或评级暗示。
- 禁止买入、卖出、建仓、加仓、减仓、满仓、仓位、止盈、止损、目标价、收益率、保证上涨、稳赚、必涨等指令或承诺。
- 主方向最多一个、备选最多一个；继续条件最多三条，停止条件一至三条，避免事项一至三条。
- `continue_conditions[*].time`、`stop_conditions[*].time` 与 `timeline[*].time` 只能填写 `09:25`、`09:35` 或 `10:30`，禁止附加日期、秒或时区；时间线必须严格按这三个时间点排列。
- 市场强弱、持续性和证据可信度分别用白话表达，不用一个数字评分代替。
- 个股仅可保留在专业层，含义是“市场热度样本（不是推荐）”。

任一门槛不满足时，不调用 webhook，状态使用 `QUALITY_CHECK_FAILED` 并列出失败项。

质量检查必须逐项执行真实布尔判断，不得先列出检查名称后无条件写入 `passed: true`。校验对象必须是最终序列化、即将发送的完整请求体。HTTP 4xx/5xx 时必须读取并记录脱敏后的响应正文和服务端错误字段，不能只记录状态码。
