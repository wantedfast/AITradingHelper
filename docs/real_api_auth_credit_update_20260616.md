# 真实接口恢复与认证额度流程更新说明

更新时间：2026-06-16

## 本次修改目标

本次变更用于把前期本地测试阶段的 AI Mock 短路逻辑恢复为真实后端接口，同时保留已经完成的用户注册、登录、额度、邀请推广、反馈奖励和管理员统计逻辑。

## 后端接口恢复

- AI 复盘接口 `/api/reports` 已恢复为真实报告生成流程，额度校验通过后调用 `_create_reports_resilient()` 进入原有复盘 Agent 链路。
- AI 盯盘计划接口 `/api/watch/plans` 已恢复为真实 `build_watch_plan()` 链路，继续在调用真实 Agent 前做额度校验。
- AI 盯盘轮询接口 `/api/watch/poll` 已恢复为真实 `evaluate_plans()`、事件去重、语音播报事件生成流程。
- 盯盘 OCR 接口 `/api/watch/ocr` 已恢复为真实图片上传与 `extract_watch_form_from_image()` 识别流程。
- 语音试听接口 `/api/watch/voice-preview` 已恢复为真实 `preview_voice_line()` 生成流程。
- 已删除后端临时 Mock 报告、Mock 盯盘计划和 Mock 响应辅助逻辑，避免后续误触发假数据链路。

## 用户注册与登录

- 手机号注册仍使用短信验证码，但现在必须同时设置密码。
- 手机号注册成功后，密码会以加盐哈希方式存储，不保存明文密码。
- 密码登录支持手机号、账号名或邮箱三种入口。
- 邮箱账号注册仍需要邮箱验证码。
- 已取消“同一 IP 只能注册一次”的限制，同一 IP 可以注册多个账号，方便真实用户场景和开发测试。

## 额度与推广

- 普通用户初始免费额度调整为 5 次。
- 普通用户调用 AI 复盘和 AI 盯盘计划时统一消耗 1 次额度。
- 普通用户额度不足时，后端会直接返回 402，不进入真实 AI 调用链路。
- 管理员账号可以使用普通用户功能，使用行为会记录为 `admin_free`，但不扣减额度。
- 邀请推广逻辑保持为“被邀请用户通过邀请链接完成新账号注册后，邀请人获得奖励额度”。
- 反馈建议被管理员采纳后，仍按现有规则奖励 10 次免费使用机会。

## 前端交互

- 登录页文案已同步为“首次注册赠送 5 次免费使用”。
- 密码登录入口提示已调整为“手机号、账号或邮箱”。
- 手机号注册表单新增密码输入框。
- 首页用户菜单会展示邀请链接原文，复制成功后按钮会短暂显示“已复制邀请链接”。
- 邀请链接在前端生成时只保留 `A-Z`、`a-z`、`0-9`、`_`、`-`，并限制长度为 32，再通过 `URLSearchParams` 写入查询参数，降低链接展示和复制过程中的注入风险。

## 验证结果

- `python -m py_compile trade_review_agent/auth_system.py trade_review_agent/api/simple_api.py` 通过。
- `npm run build` 通过。

## 部署注意事项

- 恢复真实接口后，AI 复盘、盯盘、OCR、语音试听会重新依赖项目原有真实服务配置，例如模型 API Key、行情源、OCR 和 TTS 相关配置。
- 如果真实外部服务配置缺失或不可用，请求会进入真实错误处理链路，而不是返回 Mock 成功结果。
- 额度扣减在真实 AI 调用前执行；如果后续希望“真实调用失败自动退回额度”，需要另行设计补偿事务。
